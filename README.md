# MYV Brand Website

기존 **myvbrand.com**의 정보 구조와 콘텐츠 흐름을 최대한 유지하면서,
GitHub 기반의 정적 웹사이트로 재구축·고도화하는 프로젝트입니다.

## 1차 작업 기준

- 기존 홈페이지 섹션 순서 유지
- MYV의 블루 톤 및 브랜드 메시지 유지
- PC / Mobile 반응형 개선
- 타이포그래피, 여백, 그리드, CTA 정돈
- 현재 사이트의 V.Point / News는 기존 링크로 연결
- 향후 실제 이미지 및 로고 에셋 교체 예정

## Files

- `index.html` : 메인 홈페이지
- `styles.css` : 전체 UI / 반응형 스타일
- `script.js` : 헤더, 모바일 메뉴, 스크롤 인터랙션
