# MYV 방문 기록 연결 안내

현재 준비 상태: **프론트엔드 수집 코드와 관리자 조회 UI, Cloudflare Worker 및 D1 SQL 스키마가 GitHub 저장소에 추가되어 있음.** 실제 방문 기록은 **수집 API가 배포되고 설정되기 전까지 수집되지 않음**. 연결 전에는 관리자에서 빈 데이터를 0건으로 표시하지 않음.

## 적용 순서

1. Cloudflare D1 데이터베이스를 생성합니다.
2. `analytics/schema.sql`의 SQL을 해당 D1에 적용합니다.
3. `analytics/worker.js`를 Cloudflare Worker로 배포하고 D1 바인딩 이름을 **DB**로 연결합니다.
4. Worker 환경변수 `ALLOWED_ORIGINS`에 허용 주소를 쉼표로 구분해 지정합니다. 예: `https://jyhome1228-cyber.github.io,https://myvbrand.com,https://www.myvbrand.com`. 실제 운영 도메인만 등록합니다.
5. Worker 비밀 변수 `ADMIN_TOKEN`을 충분히 긴 임의 문자열로 지정합니다. **GitHub 소스, HTML, 채팅에 토큰을 기록하지 않습니다.**
6. 루트의 `analytics-config.json`에서 `endpoint` 값을 배포된 HTTPS Worker 주소로 바꾸고 GitHub Pages에 반영합니다. 이 주소는 공개되며 비밀이 아닙니다.
7. 사이트를 열어 방문 기록을 발생시킨 뒤 `/admin/visitors.html`에서 관리자 조회 키를 입력합니다.

## 제공 기능

- 서울 시간 기준 오늘, 어제, 엊그제 페이지 조회 수
- 최근 30일 날짜별 페이지 조회
- 인기 방문 페이지, 유입경로의 **도메인 분류**, 기기 분류
- 최근 100건의 익명 이벤트 목록 (시간, 페이지, 유입 도메인, 기기)
- 30일을 초과한 원시 데이터 자동 정리 (새 요청이 들어올 때 확률적으로 실행)
- 브라우저에 쿠키, 고유 방문자 ID를 저장하지 않음. 서버에는 **IP, 전체 검색어, 전체 referrer URL, 개인 식별 정보를 저장하지 않음**.

**주의:** 조회 수는 순 방문자 수가 아닙니다. 한 사람이 여러 페이지를 보면 각각 집계됩니다. 브라우저 설정 및 광고 차단 기능에 따라 일부 조회는 수집되지 않을 수 있습니다. 사이트 유입경로는 원본 페이지가 referrer 정보를 제공하는 범위에서만 확인 가능합니다. ChatGPT·네이버 등도 항상 구분되는 것은 아닙니다.

## 보안 및 개인정보

- 조회 API(`GET /stats`)는 서버 비밀 변수 `ADMIN_TOKEN`을 확인합니다. 관리자 HTML 주소만 안다고 조회할 수 없습니다.
- 관리자 입력 토큰은 탭 메모리에만 보관합니다. 새로고침 시 재입력해야 합니다.
- Worker는 허용된 Origin만 요청을 처리합니다. 이는 데이터 수집 경계이며 인증 수단은 아닙니다.
- 공개 페이지의 방문 기록 수집 및 처리 내용을 사이트 개인정보처리방침에 반영하고, 필요 시 관련 법적 검토를 진행한 뒤 활성화합니다.
- 네트워크 요청 성공 여부는 GitHub Pages 배포 후 실제로 점검해야 합니다. 연결 전 방문 기록의 소급 복구는 불가합니다.

현재 홈페이지 수집은 `script.js`가 `visitor-track.js`를 로드하는 방식입니다. 수집 API가 미연결이면 요청을 보내지 않습니다.
