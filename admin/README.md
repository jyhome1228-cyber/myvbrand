# MYV 관리자

`/admin/`에서 공개 뉴스 데이터를 관리합니다. 기존 뉴스 38건을 그대로 유지하며 문의나 방문 통계의 가짜 데이터는 사용하지 않습니다.

## 사용 흐름

1. 대시보드에서 전체 뉴스, 본문 미등록, 미반영 변경, 남은 확인 항목을 확인합니다.
2. 뉴스 관리에서 분류·상태·검색으로 기사를 찾습니다.
3. 한국어·영어 제목, 요약, 본문, 대표 이미지 URL, 원문 링크를 편집하고 미리보기를 확인합니다.
4. **초안 저장**은 현재 브라우저의 localStorage에만 저장합니다. 비공개 업무·고객 정보는 입력하지 않습니다.
5. 저장소 연결에서 해당 저장소의 Contents 읽기·쓰기 권한을 가진 GitHub fine-grained token을 입력합니다. 토큰은 현재 탭의 메모리에만 유지됩니다. 새로고침하면 다시 연결해야 합니다. 토큰을 채팅으로 전달할 필요는 없습니다.
6. **사이트 반영**에서 변경 항목을 확인한 뒤 반영합니다. `main`의 `news-posts.json`만 갱신하며 GitHub Pages의 배포 완료 후 사이트에 표시됩니다.

GitHub 계정 권한이 공개 뉴스 변경 권한입니다. 별도의 비밀번호를 JavaScript에 하드코딩하지 않습니다. 현재 화면은 고객 정보가 있는 비공개 CRM이 아닙니다.

## 데이터와 안전장치

- 뉴스 목록·상세·메인 최신 3건은 `news-posts.json`을 함께 읽습니다. 한국어·영문 페이지 모두 같은 데이터를 사용합니다.
- 기존 뉴스의 추가 메타데이터는 편집 시 유지합니다.
- 본문은 HTML로 실행하지 않고 텍스트로 렌더링합니다. 빈 줄로 문단을 구분하고 `## 소제목`, `**강조**`, Markdown 링크, 이미지 URL 한 줄을 사용할 수 있습니다.
- 영어 필드: `titleEn`, `summaryEn`, `bodyEn`. 기존 영문 제목·요약 사전은 fallback으로 유지합니다. 영어 본문이 없으면 기존 한국어 본문을 표시합니다.
- 본문 없는 기존 8건은 관리자에서 보완 대상으로 표시합니다. 공개 상세에서는 원문 링크를 제공합니다. 본문을 새로 작성한 것으로 간주하지 않습니다.
- 새 글을 본문 없이 반영할 수 없습니다. 단, 유효한 원문 링크를 입력하고 원문 안내를 선택하면 외부 기사로 등록할 수 있습니다.
- 뉴스 보관은 복원이 가능합니다. 사이트 반영 전까지 공개 데이터는 바뀌지 않습니다. 반영 후 공개 JSON에서 제외되지만 기존 정적 `/news/*.html` 주소와 Git 이력까지 제거하는 기능은 아닙니다.
- 반영 직전 최신 JSON과 SHA를 읽습니다. 다른 사람이 동일 기사를 변경했다면 중단하고, 서로 다른 기사의 변경은 보존해 합칩니다. SHA 충돌 시 덮어쓰지 않습니다.
- 백업은 뉴스·브라우저 초안·보관함·체크리스트를 포함합니다. 액세스 토큰은 포함하지 않습니다.
- 브라우저 데이터를 지우거나 다른 기기로 옮기기 전에 백업을 내보내야 합니다.

## 문의와 통계

현재 문의 폼은 FormSubmit → `info@myv.co.kr` 메일 방식입니다. 어드민 문의 목록, 처리 상태, 내부 메모, 실제 방문자 통계, 고객용 관리자 로그인, 이미지 직접 업로드는 아직 연결되지 않았습니다. 조회할 수 없는 데이터에 0건이나 가짜 값을 표시하지 않습니다.

후속 개발은 인증된 별도 서버/저장소를 마련한 뒤 문의 저장 → 관리자 권한 확인 → 목록·상세·상태·내부 메모 → 알림 순서로 진행합니다. 고객 개인정보를 공개 GitHub 저장소나 localStorage에 저장하는 방식으로 확장하지 않습니다.

## 남은 홈페이지 수정

- 입점제안 히어로 이미지 크기·겹침·잘림, 반복 손 배경
- 뉴스 8건 본문·이미지 및 추가 소식 확인
- V.Point 용어·지급·소멸·취소 기준 확정, 메뉴 노출
- WITH US 직접 이동 방식과 모바일 하위 메뉴 설명, 쇼핑몰 복귀 경로
- 문의 메일 실제 수신 확인, 개인정보 임시 문안 확정
- 메인 가치소비 카피, 회사가 제공한 실제 브랜드·제품·성과 자료
- 영문 본문과 모바일 실화면 검수 (언어 전환 시 기사·문의 파라미터 유지는 이번 변경에 반영)
- 검색·공유 미리보기·404·방문 분석 범위 확정
- 추가 제안: 계산 결과 바로 아래 신청 버튼·메인 간단 계산기 범위 검토

체크리스트에서 상태를 변경할 수 있지만 홈페이지 내용이 자동으로 수정되는 기능은 아닙니다.
